# EvidenceTwin frontend

Run `npm ci` and `npm run dev` from this directory. Build with `npm run build`, check lint with `npm run lint`, run unit tests with `npm test`, and browser checks with `npm run test:e2e`.

See the [project README](../README.md), [Flask integration guide](../docs/INTEGRATION_GUIDE.md), and [Phase 5 acceptance report](../docs/PHASE_5_ACCEPTANCE.md) for current implementation, contracts and verification limits. No Flask backend is included. Production API failures never fall back to scientific fixtures.
