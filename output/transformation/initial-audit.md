## Findings

- Browser-reproduced: Start Investigation navigates to `?prepare=1`, mounting AnalysisBuilder's upload-first five steps.
- Composer accepts XLSX outside API submission; the apparent attachment cannot participate in research.
- Case endpoints expose labeled educational inputs, not persisted user cases. Saving research requires a configured provider and immediately starts execution.
- Provider settings have no built-in role/owner boundary. Auth is an optional hook without an account model. Local records are globally scoped.
- Actual exploratory ingestion, SQLite persistence, original private file storage/hashes, model review, cross-review, adjudication, cancellation/retry, audit, JSON reports and browser printing exist.
- Scientific source/statistical verification, Neutral Twin, benchmark scoring and hosted PostgreSQL execution integration remain unavailable/unvalidated.
- Navigation advertises unavailable benchmark creation and future integrations. Settings contain disabled exports, notification placeholders and provider credentials.
- UI uses repeated status explanations and layered green palettes. Inspection views are valuable but raw JSON/identifiers and execution terminology dominate ordinary tasks.

## Implementation direction

One prompt-led preparation surface → persist a real case and evidence revision → explicitly authorize exploratory Council processing → inspect real analysis → export available report. Preserve historical analyses and all scientific exclusions. Add scoped case/revision storage and server-enforced operator controls; do not deploy, migrate legacy ownership or cut over experimental execution infrastructure. Replace palette with slate/cobalt, simplify navigation and ordinary settings. Final acceptance belongs to the owner.

## Design direction

Operate/Read, code-first. Grounded candidates: research journal, conference proceedings, library catalogue, systematic review, evidence atlas, academic reading room, annotated research notebook. Impeccable assigned candidate 7 (`seed:1e8b2d9f9648a322`). Its contribution is a persistent question above evidence and notes, and a readable revision history beside actual review runs. Standard web controls carry the work. Challengers (annual plate, cassette insert, transit map, glass timetable) lose task clarity or violate the requested material constraints; retain disciplined alignment and continuity, not ornament. User's explicit instruction to proceed governs routine choices; no extra design approval gate.
