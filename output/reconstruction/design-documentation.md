1. Palette: neutral paper/charcoal themes with restrained semantic cobalt and written status labels.
2. Type: Manrope/Alan Sans, 26px application headings (24px mobile), readable original scientific prose and IBM Plex Mono data.
3. Layout: 224px sidebar, 56px header, read-first saved investigations, Council perspectives and report contents disclosure on mobile.
4. Forms: 7px shared control corners, 14px composer, contextual evidence/source controls and optional detail disclosures.
5. Named rules: Semantic Surface Rule and Source Wording Rule; active-theme tokens and deterministic supplied-text prefixes.
