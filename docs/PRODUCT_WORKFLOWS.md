# Researcher workflow

Implemented local journey, 2026-11-08. Primary navigation is Home → New investigation → Cases → Chart reviews → Reports. The educational library is separate and read-only. In account mode sign in with an operator-issued account; researchers do not configure shared provider credentials.

1. Upload an original scientific chart, initially focused on healthcare and public-health visualization. Optionally add a question or context, an underlying CSV/structured JSON table and a source. An attached PNG/JPG/WebP image permits saving without a written question. The visible standard request asks for presentation inspection, evidence and limitations. It is stored as the inspection request while optional original context remains intact. A question without an image still supports the existing research workflow. Use the composer’s add menu for supporting evidence, sources and extra claims. Review opens a compact mode menu, with study context and local draft persistence in its secondary Study settings editor. All menus and editors float outside document flow and preserve entered values when dismissed. File previews and editable/removable source and claim chips represent actual inputs. Visual review and Multi-perspective review map to the existing focused and Council settings. Create investigation saves a real case with its first immutable evidence revision. A provider is not required, and this action does not begin model processing.
2. Saved investigations open in a reading view with the full original question and saved evidence. Choose Edit question & evidence to edit question/metadata, retain or remove selected files, attach new bytes, and save a new revision. Closing the editor returns to reading without discarding tab-memory edits. Earlier question text, original filenames, bytes and hashes remain inspectable. Opening a saved case computes a complete-table descriptive preview without fetching URLs. Source retrieval happens only within a newly authorized review.
3. Inspect a supported CSV/structured JSON table, inspect images or download originals. PDF bytes can be retained/downloaded, but are not extracted or scientifically checked. XLSX is unavailable. See [API limits](API.md).
4. When a provider is configured, explicitly authorize external processing of the saved revision. Consent explains selected complete-table records, deterministic results, images and retrieved public-source excerpts sent to the operator's provider. Reviewers may request bounded exact-match queries. Council requires files, an educational case or a source URL; a question-only case is still valid to save. Save unsaved changes before running. There is no automatic run or automatic external-processing retry.
5. Follow actual queued/running/completed/failed/cancelled states, open the associated Council record, inspect actual quantitative findings and separate check coverage, read individual reviewer perspectives, expand original contributions, inspect disagreements, evidence and the readable audit timeline, then read/export an available report as JSON or browser print. Reports provide contents navigation, with a disclosure on mobile; print omits application controls. Empty/error/unavailable states stay explicit. A model interpretation is not a scientific verdict.

Compact display titles use whitespace-normalized, bounded prefixes of supplied titles/questions with an ellipsis when shortened; they are not generated interpretations. The full question remains in the investigation reading view, and the report exposes its original question. Paragraph rendering preserves supplied wording and paragraph boundaries. See [the visual system](../DESIGN.md).

The case provenance/history rail links immutable revisions and associated real runs. A stale save or competing active run produces a conflict rather than overwriting evidence. Case-linked analyses/reports are retained and protected from legacy deletion. Standalone legacy analysis/report deletion remains subject to server permissions.

New investigation drafts stay in tab memory by default, including selected File objects, and survive same-tab navigation. Optional browser text persistence is explicit, per account, and excludes file bytes. Legacy local-mode text stays local. Reload cannot restore unsaved file selections; save the case for server persistence. Authentication selects the correct draft owner before research renders; late save acknowledgements target the original owner. Saved case edits also survive same-tab navigation. Dirty saved-case edits trigger a browser unload warning even while the editor is closed. Research content keeps its supplied language and direction; changing Arabic/English chrome does not translate scientific text.

Operator provider administration is separate from ordinary researcher preferences. Optional accounts do not establish team sharing, institutional roles or a hosted pilot. See [architecture](ARCHITECTURE.md), [scientific scope](SCIENTIFIC_SCOPE.md) and [deployment/rollback](DEPLOYMENT_ROLLBACK.md). Final acceptance belongs to the owner.

The [evidence-processing guide](EVIDENCE_PROCESSING.md) documents supported entity/year selection, Decimal arithmetic, source snapshots, role queries, structured limitations and unavailable Blind Optics. Historical reviews retain their original findings. New processing requires a new authorized run.

## Unified results and translated reports

The results overview opens with the recorded visual observation and original chart, followed by supporting Council interpretation, descriptive observations and the separate scientific assessment. Execution completion remains a separate status. Display titles use verbatim quoted claims or remove recognized English/Arabic instruction wrappers before applying the bounded prefix rule. The complete original question remains inspectable.

A desktop narrative sits beside an evidence workspace with charts, data and sources. Mobile reading and keyboard order follow the introduction, evidence, then detailed narrative. Exact uploaded/retrieved observations drive plots. Source rows, hashes, calculation methods and original images remain accessible. Compact Council perspectives disclose original explanations, claim positions and provenance. Actual disagreements and grouped limitations remain distinct. Blind Optics is explicitly unavailable.

New version-4 reports open with the recorded visual summary. Older reports retain their original sections and findings. Translation and record metadata disclose contextually. English/Arabic machine translation is an explicit action. A derivative is tied to its original report hash and owner. If a translated passage changes protected numbers or references, the original passage is retained and the derivative is labeled partial. The original report and its JSON export remain separate. Browser printing expands preserved records and reviewer explanations, then restores the previous reading state. There is no server-generated PDF service.
