## Maintain these documents

Update the guide responsible for the changed behavior. Keep setup commands in Development, contracts in API, methods and connector limits in Evidence processing, and scientific approval boundaries in Scientific scope. Link between guides when details belong elsewhere.

Preserve dated reports and decisions with their original scope. Archive superseded guidance with a discoverable link and record any path changes. Keep private evidence, credentials and runtime backups outside documentation. Owner acceptance and scientific validation require their own evidence.
